순서와 실패 처리

1사용자가 사진을 올리고 '이 사진으로 읽기'를 누른다
2앱이 오늘 사용량을 하나 쓴다. 한도(기본 150회)를 넘으면 예시 메뉴판과 안내
3OCR 키가 있으면 CLOVA OCR 호출 (30초 제한). 줄이 2개 미만이면 실패로 본다
4OCR 줄을 Claude에 보낸다. 키가 없으면 사진을 Claude가 직접 읽는다
5stop_reason이 refusal 또는 max_tokens면 실패로 본다
6코드가 규칙 판정, 닮은꼴, 묶음(모두 편히, 몇 명만, 모두 피하기), 조합 3안을 만든다
7메뉴판이 아니면(OCR 글자 2줄 미만이거나 is_menu=false) '올린 사진이 메뉴판이 맞는지 다시 한번 확인해 주세요.' 알림을 띄우고 찍기 화면에 머문다. 다른 실패는 '글씨가 잘 보이게 다시 찍어 주세요'
8사람 목록이 바뀌면 Claude를 다시 부르지 않고 6만 다시 계산한다
