한 줄 소개
처음 보는 해외 메뉴판을 찍으면, 같이 먹는 사람마다 각자 아는 음식에 빗대어 무슨 맛인지 알려 주고, 모두가 먹을 수 있는 주문까지 도와주는 모바일 웹앱.

1피드백과 바뀐 점

받은 피드백이번 설계에서 바꾼 것
번역만으로는 무슨 맛인지 모른다. 맛을 상상하게 해 주는 것이 가치다각자 즐겨 먹는 음식(나라 상관없이)을 기준으로 닮은꼴을 아주 / 꽤 / 조금으로 알려 주고, 같은 점과 다른 점, 향과 식감 키워드, 맛 지도를 보여 준다
효도에 갇히지 말 것. 아이가 더 까다롭다혼자 / 여럿이로 시작한다. 가족 단위로 사람마다 입맛을 저장하고, 아이는 '처음 보는 음식', '골라내는 경우', '잘 먹는 재료'를 따로 받는다
부모님을 아픈 사람으로 그리지 않아 좋다질병, 복약 정보는 받지 않는다. 좋아하는 맛, 피하고 싶은 맛, 못 먹는 것, 알레르기만 받는다
한식당이 없는 자유여행, 패키지 여행의 자유 식사 시간파리 외곽처럼 한식당이 없는 곳이 기본 상황. 패키지는 '모이는 시간'에서 거꾸로 계산해 다녀올 수 있는 식당만 먼저 보여 준다
여러 명이면 메뉴 조합을 추천해 달라조합 3안(모두 만족, 현지 맛 도전, 빨리 나와요). 가장 덜 맞는 사람 기준으로 고르고 이유를 보여 준다
메뉴판 번역(예: 프랑스어에서 한국어)메뉴판 순서 그대로 옮기기, 원문과 함께 보기, 요리 용어 풀이, 흐린 줄 표시
유사도 아이디어가 신박하다. 구현이 중요하다실제 사진에서 글씨를 따고(CLOVA OCR) 설명을 만드는(Claude) 동작하는 MVP를 배포한다. 닮은꼴과 조합은 코드로 계산해 결과를 설명할 수 있게 한다

이전 설계(부모님 걸음 기준 일정 짜기)는 보류한다. 걷는 속도 계산(Bohannon, 2011)은 자유 식사 시간 화면에서 가장 천천히 걷는 사람 기준으로 다시 쓴다.

2문제와 고객

겪는 문제
  • 번역 앱은 이름만 바꿔 줄 뿐, 그 요리가 어떤 맛인지는 알려 주지 않는다
  • 가족 안에서도 입맛이 다르다. 한 사람은 새로운 맛을, 아이는 익숙한 맛을 원한다
  • 알레르기와 못 먹는 재료를 현지어로 정확히 전하기 어렵다
  • 패키지 자유 식사는 시간이 정해져 있어 고를 시간이 짧다
고객
  • 1차 아이나 부모님과 함께 한식당이 없는 지역을 자유여행하는 가족
  • 2차 패키지 여행의 자유 식사 시간을 쓰는 여행객
  • 확장 혼자 여행하는 사람, 해외 시니어 상품을 기획하는 여행사

근거: 2025년 해외관광객 2,955만 명으로 역대 최대(한국관광공사, 2026.2.), 2026년 5월 해외관광객 중 60세 이상 16.0%(한국관광공사, 2026.7.). 참가신청서 참고문헌과 같다.

3핵심 기능

기능 1. 메뉴판 번역과 맛 그려 주기 구현

  • 메뉴판 사진에서 CLOVA OCR로 글씨를 줄 단위로 딴다. 확신도가 낮은 글자는 표시해 둔다
  • Claude가 줄을 메뉴로 묶고, 빠진 악센트를 바로잡고(gratinee를 gratinée로), 우리말 이름, 한 줄 설명, 요리 용어, 들어간 재료, 맛 수치 8개, 맛·향·식감 키워드를 구조화된 JSON으로 만든다
  • 사람마다 즐겨 먹는 음식과 비교해 가장 닮은 음식, 단계, 같은 점, 다른 점을 코드로 계산한다

기능 2. 사람별 판정, 메뉴 조합, 주문 카드 구현

  • 메뉴마다 사람별 편히 / 조심 / 피하기와 한 줄 이유. 알레르기와 못 먹는 재료는 LLM 판정과 상관없이 코드에서 피하기로 고정한다
  • 조합: 사람마다 한 접시 + 나눠 먹을 후식. 가장 덜 맞는 사람의 점수가 가장 높은 조합(maximin)을 먼저, 같으면 서로 다른 메뉴와 합계 점수로 고른다
  • 주문 카드: 알레르기 문장을 맨 위에, 현지어 주문 줄과 부탁 문장, 소리 내어 읽기

기능 3. 주변 식당과 패키지 자유 식사 시간 구현 보행 경로 API 연동 예정

  • 지금 위치(브라우저 위치 허용)로 주변 실제 식당을 불러온다. 요리 종류로 대표 메뉴를 붙이고 사람별로 먹을 메뉴와 닮은꼴을 미리 보여 준다. 위치는 저장하지 않는다
  • 남은 시간 = 모이는 시각 − 지금. 식당마다 가기 + 기다림 + 식사 + 돌아오기 + 여유가 남은 시간 안에 드는지 본다
  • 걷는 속도는 일행 중 가장 느린 사람 기준 (Bohannon 2011 연령별 보행 속도, 아이 1.0 m/s 초안)
  • 식당: 한국 안은 카카오 로컬, 해외는 Geoapify(둘 다 키가 있을 때), 없으면 OpenStreetMap 검색(Nominatim, 1~2초). 요리 종류가 없으면 가게 이름으로 짐작한다. 걷는 길은 아직 직선 거리 × 1.3이라 OpenRouteService로 바꾼다

더하기. 후기와 먹은 뒤 설문 구현

  • 후기는 이 식당의 이 메뉴를 먼저, 없으면 다른 식당의 같은 메뉴로 넓힌다
  • 설문(실제 주문, 맛이 그려졌는지, 예상보다 강한 맛, 다시 추천)이 쌓이면 다음 사람에게 '생각보다 매울 수 있어요'처럼 미리 알려 준다

맛 수치 8개(짠맛, 단맛, 매운맛, 신맛, 감칠맛, 향의 세기, 기름진 정도, 부드러움)의 가중 거리로 맛 유사도를 구하고, 주재료가 같으면 +0.18, 조리법이 같으면 +0.08을 더한다. 주재료가 다르면 '조금 닮았어요'까지만 준다. 0.78 이상 아주, 0.64 이상 꽤, 0.50 이상 조금.

5다른 서비스와 다른 점

구분사진 번역 앱지도 앱 리뷰모시고
알려 주는 것요리 이름의 뜻별점과 후기그 사람이 아는 음식에 빗댄 맛, 같은 점과 다른 점
기준없음다른 사람의 평가같이 먹는 사람마다 따로
여러 명해당 없음해당 없음사람별 판정, 메뉴 조합
알레르기해당 없음해당 없음규칙으로 고정, 주문 카드 맨 위
시간 제약해당 없음거리 표시모이는 시간 역산, 가장 느린 사람 기준

비교는 각 서비스의 공개 소개 기준이며 제출 전 최신 버전으로 다시 확인한다.

8지금 상태와 남은 일

  • 완료 모바일 MVP 화면 15개, OCR과 LLM 연결, 메뉴판이 아닌 사진 알림, 닮은꼴과 조합, 주문 카드, 주변 식당(현재 위치), 자유 식사 시간, 후기와 설문, 입맛 저장(쿠키 코드), 공개 배포(Render), 테스트 7개
