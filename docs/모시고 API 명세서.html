모시고 API 명세서

가족 메뉴판 도우미, 외부 API와 내부 함수와 데이터 구조 | 팀 NEXUS | 2026.11.03

CLOVA OCRClaude주변 식당내부 함수데이터 구조저장소설정값REST 부록
모시고 MVP는 Streamlit 앱 하나로 동작한다. 화면과 계산이 같은 Python 프로세스에 있어서 따로 여는 REST API는 없다. 이 문서는 외부 API 2개(CLOVA OCR, Claude), 내부 모듈 함수, 데이터 구조, 저장소, 설정값을 정리한다. 네이티브 앱으로 넓힐 때 쓸 REST 엔드포인트는 부록에 둔다 (FastAPI 시제품에 구현되어 있음).

1외부 API: 네이버 CLOVA OCR (General, V2)

항목값
호출POST {CLOVA_OCR_URL} (콘솔의 API Gateway 연동 General 호출 주소, …/general)
헤더Content-Type: application/json, X-OCR-SECRET: {CLOVA_OCR_SECRET}
제한한 번에 사진 1장, 50MB 이하. 앱은 8MB를 넘거나 JPG/PNG가 아니면 JPEG(긴 변 2000px)로 바꿔 보낸다. 시간 제한 30초
언어lang은 ko, ja, zh-TW. 보내지 않으면 도메인 설정. 라틴 문자는 악센트가 빠질 수 있어 다음 단계(Claude)에서 바로잡는다
{
  "version": "V2",
  "requestId": "4f1c…(uuid)",
  "timestamp": 1793678400000,
  "images": [{ "format": "jpg", "name": "menu", "data": "(base64)" }]
}

응답에서 쓰는 값

필드뜻앱에서
images[0].inferResultSUCCESS / FAILURE / ERRORSUCCESS가 아니면 실패 처리
fields[].inferText읽은 글자 (단어 단위)줄로 이어 붙임
fields[].inferConfidence0~1 확신도0.6 미만이면 글자 뒤에 (?), 줄에 [흐림]
fields[].lineBreak줄의 마지막 단어인지줄 나누기 기준

앱 안에서 넘기는 모양 (core.ocr.read의 반환값)

{ "lines": [ {"text": "Soupe a l'oignon gratinee 9 €", "conf": 0.9, "low": false},
             {"text": "Plat(?) du(?) j0ur(?) 18 €", "conf": 0.35, "low": true} ],
  "words": 52 }

2외부 API: Claude (Messages, 구조화 출력)

항목값
SDKanthropic 2.3.0 (Python), client.beta.messages.stream(...) 후 get_final_message()
모델claude-opus-5-5, max_tokens 32000, output_config.effort "low"
출력 형식output_config.format = {"type": "json_schema", "schema": …} (아래 스키마)
대체 모델betas=["server-side-fallback-2026-07-01"], fallbacks="default"
실패 판정stop_reason이 refusal 또는 max_tokens면 예외. 앱은 예시 메뉴판으로 이어 감
시스템 프롬프트메뉴판 순서와 묶음 유지, 흐린 줄 표시, 맛 수치 8개 짐작, 사람별 판정 기준(편히, 조심, 피하기). 건강이나 병이 아니라 입맛과 취향으로 말하기, 아이는 행동으로 말하기. 사람별 입맛 요약을 붙임
사용자 메시지OCR 경로: 줄 번호가 붙은 OCR 글자와 바로잡기 안내 (텍스트만). 사진 경로: 사진(base64) + 짧은 요청
걸린 시간OCR 경로 약 43초, 사진 경로 약 69초 (메뉴 12~16개 기준)

출력 스키마 (메뉴 하나)

필드형식설명
section_orig, section_kostring묶음 이름 원문과 우리말 (예: ENTRÉES, 먼저 먹는 요리)
name_orig, reading, name_kostring원래 이름(악센트 바로잡음), 한글 읽기, 뜻
price, desc_kostring가격 원문, 쉬운 한 문장 설명
glossary[{term, meaning}]요리 용어 풀이
unreadableboolean흐려서 이름을 알 수 없음
coursestarter / main / side / dessert / drink조합 계산에 씀
containsenum 배열견과류, 우유, 달걀, 밀가루, 갑각류, 조개류, 생선, 돼지고기, 소고기, 닭고기, 버섯, 양파, 날것, 술
ingredient, cookingenum주재료, 조리법 (세계 음식 표와 같은 값)
t_salty … t_softnumber 0~1짠맛, 단맛, 매운맛, 신맛, 감칠맛, 향의 세기, 기름진 정도, 부드러움
taste_kw, aroma_kw, texture_kwstring 배열맛, 향('~ 향'), 식감 키워드
kids_only, chef_pick, share_okboolean어린이 메뉴, 가게 추천, 나눠 먹기 좋음
serve_minutesinteger나오는 데 걸리는 시간 짐작
people[{name(enum), verdict(편히/조심/피하기), reason}]사람별 판정 초안. 편히면 reason은 빈 문자열

맨 위: {is_menu, restaurant, menu_language, language_code(BCP 47), items[]}. is_menu가 false면 앱은 '올린 사진이 메뉴판이 맞는지 다시 한번 확인해 주세요.'를 보여 준다.

2-1외부 API: 주변 식당과 위치

API호출쓰는 값조건
브라우저 위치navigator.geolocation (streamlit_js_eval의 get_geolocation)위도, 경도사용자가 허용할 때만. 저장하지 않음
카카오 로컬GET https://dapi.kakao.com/v2/local/search/category.json, category_group_code=FD6, x, y, radius=900, sort=distance, 페이지 3개place_name, x, y, category_name(요리 종류), place_url한국 안이고 KAKAO_REST_KEY가 있을 때
Geoapify PlacesGET https://api.geoapify.com/v2/places, categories=catering.restaurant,catering.fast_food,catering.cafe, filter=circlename, lat, lon, categories, opening_hoursGEOAPIFY_KEY가 있을 때
OpenStreetMap NominatimGET https://nominatim.openstreetmap.org/search, q=restaurant / fast food, viewbox 주변, extratags, namedetailsname, name:ko, cuisine, opening_hours키 없음, 1~2초. 사용 정책에 맞춰 1초에 한 번만 묻고 15분 동안 결과를 기억
OpenStreetMap OverpassPOST /api/interpreter, amenity=restaurant|fast_food|cafe, around 900m. 공개 서버 4곳에 동시에 묻고 먼저 온 답을 씀name, name:ko, cuisine, opening_hours키 없음. 공개 서버라 20~35초 걸릴 수 있음

요리 종류(cuisine)는 대표 메뉴로 바꾼다 (예: vietnamese는 쌀국수, thai는 팟타이와 똠얌꿍). 대표 메뉴의 재료는 일반적인 조리법으로 짐작해 알레르기 규칙에 쓴다 (팟타이는 견과류). 요리 종류를 모르는 가게는 '메뉴 정보가 없어요'로 표시한다.

3내부 모듈 함수

함수입력출력
ocr.read(data)사진 bytes{lines, words}. 환경 변수 CLOVA_OCR_URL, CLOVA_OCR_SECRET 필요
ocr.group(fields)CLOVA fields{lines, words}
menu2.read_menu_text(ocr, people)OCR 결과, 오늘 같이 먹는 사람Claude 원본 JSON (위 스키마)
menu2.read_menu(jpeg, media_type, people)사진, 사람같음 (OCR 키가 없을 때)
menu2.enrich(raw, people)원본 JSON, 사람Scan: items[]에 taste[8], per[], group, headline, map, id 추가. judged(음료와 흐린 줄 뺀 정렬 목록), people
menu2.combos(scan, people)ScanCombo 최대 3개 (all, local, fast)
world.best_match(item, favorites)메뉴, 즐겨 먹는 음식Match 또는 None
order.card(scan, people, lines, requests)lines [{item_id, count}], 부탁(한국어)OrderCard. 언어는 order.lang_key(scan): language_code로 11개 언어 중 고르고(중국어는 간체/번체 구분), 없으면 영어
reviews.feedback(menus), menu2.apply_feedback(scan, fb)메뉴 원래 이름 목록메뉴별 {n, again, imagine, boost}. boost를 메뉴 순서와 조합 점수에 더함
nearby.fetch_spots(lat, lng, radius), nearby.rank_spots(...)위치, 같이 가는 사람, 걷는 속도둘러볼 곳: 카카오(AT4 관광명소, CT1 문화시설) 또는 Nominatim(park, museum, attraction, playground, viewpoint, gallery). 사람에 맞춘 순서와 이유 한 줄
nearby.find(lat, lng, radius)위치(출처 이름, 원본 목록). 카카오, Geoapify, Nominatim, Overpass 순
nearby.to_places(elements, lat, lng)원본 목록식당 목록: id, name, kind, lat, lng, wait_min, meal_min, dishes[], distance_m, note(영업시간)
freemeal.plan(people, now, meet, buffer, meet_pt=None, restaurants=None)"HH:MM" 두 개, 여유 분, (지금 위치, 주변 식당)FreeMeal. 위치가 없으면 예시 동네
reviews.save(...), stats(menu), caution(menu), reviews(menu, restaurant)설문 값, 메뉴 원래 이름저장, 요약, 주의 문구, 후기 {here, other, count, avg}
store.load(code), save(code, people), take_scan()기기 코드사람 목록, 저장, 오늘 사용 가능 여부

5저장소 (SQLite)

테이블열용도
peoplecode TEXT PK, data TEXT(JSON), updated REAL기기 코드별 사람 목록
surveyid, ts, restaurant, menu, ordered, imagine(1~5), stronger(쉼표), again, comment, who먹은 뒤 설문, 한 줄 후기
usageday TEXT PK, scans INT하루 사진 읽기 횟수 (API 비용 보호)

Render 무료 서버는 다시 시작하거나 다시 배포하면 파일이 지워진다. 시연 뒤 오래 보관하려면 외부 DB로 옮긴다.

6설정값과 비밀값

이름어디설명
ANTHROPIC_API_KEY배포처 비밀값 (Render 환경 변수)Claude 호출 키
CLOVA_OCR_URL, CLOVA_OCR_SECRET배포처 비밀값CLOVA OCR General 호출 주소와 Secret Key. 없으면 사진을 Claude가 직접 읽음
KAKAO_REST_KEY배포처 비밀값카카오 로컬 REST API 키 (한국 안 주변 식당, 선택)
GEOAPIFY_KEY배포처 비밀값Geoapify 키 (해외 주변 식당, 선택)
MOSHIGO_DAILY_SCANS환경 변수하루 사진 읽기 한도, 기본 150
MOSHIGO_DB환경 변수SQLite 파일 위치, 기본 core/data/moshigo.db

비밀값은 저장소에 올리지 않는다 (.streamlit/secrets.toml은 .gitignore). 예시는 .streamlit/secrets.example.toml.
