# 식사류 우선 추천

개인 입맛 평균만 정렬하면 소스가 맨 앞에 올라올 수 있었습니다. 이제 API의 식사 역할이 **주식 또는 주요리**이고 구성원 전원의 점수가 유효한 메뉴를 먼저 정렬하고, 그 안에서 상위 두 개만 추천합니다.

| 변경 전 | → | 변경 후 |
|---|---|---|
| 소스·반찬도 평균이 높으면 최상단 추천 | → | 주식·주요리 후보 안에서 평균 상위 2개 추천 |
| 그뤼네 소스 · 케스페츨레 | → | 케스페츨레 · 셀러리 슈니첼 |

- 평균 계산과 개별 점수는 바꾸지 않았습니다. 소스·음료·후식 등 나머지 메뉴도 목록에서 볼 수 있습니다.
- 음식 이름에 `소스`가 들어간다는 이유로 제외하지 않습니다. 소스를 곁들인 슈니첼·고기 구이도 역할이 주요리면 유지합니다.
- 역할 정보가 없거나 `unknown_fields`에 `meal_roles`가 있으면 상위 추천을 보류합니다. 식사 후보가 하나면 추천 배지도 하나만 표시합니다.
- 이전 시각 검증 fixture가 생략했던 `food_type`, `meal_roles`, `unknown_fields`는 최초 실제 API 응답에서 복구했습니다. 기존에 보존된 프로필 필드가 원본과 모두 같은지 먼저 확인했으며, 음식명 규칙으로 역할을 꾸며 넣지 않았습니다.
- 케스페츨레 이미지는 재사용했습니다. 셀러리 슈니첼 이미지만 기존 OpenAI API와 고정 모델 `gpt-image-2-2026-04-21`로 한 장 추가 생성했습니다. 소스 이미지도 기록으로 보존합니다.

## 검증

- UI 회귀 **53개 통과**. 높은 점수의 소스·음료·후식 제외, 역할 누락·불확실, 소스를 포함한 주요리 유지, 단일 식사 후보, 평균 보존을 확인했습니다.
- 현재 19개 메뉴에서 상단 2개가 케스페츨레·셀러리 슈니첼이며 그뤼네 소스는 추천 배지 없이 아래에 표시됩니다.
- 새 셀러리 슈니첼 PNG(1024×1024)의 파일 검증·실제 음식 형태 시각 검토를 완료했습니다. [생성 파일·프롬프트](../../../core/data/generated-menu-images/README.md)
