# 새 메뉴판 상단 두 카드 자동 AI 이미지

메뉴판마다 다른 상단 음식에 자동으로 이미지를 생성합니다. 이전의 수동 이미지 파일 추가 단계를 없앴습니다. 저장된 같은 음식 설명의 이미지가 있으면 재사용하고, 없으면 Food Guide 서버에 작업을 접수합니다.

- 기존 식사류 우선·구성원 평균 정렬은 유지합니다. **현재 표시 순서의 상단 두 카드**가 이미지 대상이며, 추천 배지 조건과 이미지 제공 조건은 분리했습니다. 제한된 메뉴에 이미지가 있어도 추천 배지를 부여하지 않습니다. 오래된 분석에서는 새 이미지 요청을 시작하지 않습니다.
- 최초 표시에는 `AI 이미지 생성 중`을 보여 주고 2초 간격으로 상태를 확인합니다. 완료하면 해당 카드만 바뀌며, 완료 후 자동 폴링을 멈춥니다. 실패하면 상태와 `이미지 다시 생성` 버튼을 표시합니다. 참고 그림을 AI 생성 결과처럼 표시하지 않습니다.
- 새 이미지 API는 음식명·재료·조리법만 받습니다. OpenAI 키는 기존 Food Guide 서버에 있으며 브라우저나 소비 앱에 복사하지 않습니다. 기본 모델은 `gpt-image-2-2026-04-21`, 기존 stage3 프롬프트·일일 호출 한도·SDK 자동 재시도 없음 정책을 사용합니다.
- 이미지 작업은 분석과 분리한 SQLite·worker에서 실행합니다. 같은 인증 소유자·음식 설명·모델·프롬프트 버전은 같은 ID이고 7일간 결과를 재사용합니다. 접수 응답 유실·새 브라우저 세션에서도 같은 POST는 중복 생성하지 않습니다.
- 실패 재시도는 사용자가 누른 새 `retry_token`에만 허용합니다. 같은 재시도 토큰을 반복 전송해도 추가 생성하지 않습니다. 429 대기 시간과 서버의 일일 호출 한도를 유지합니다.
- 앱은 작업 ID·음식 설명 해시·PNG SHA-256·파일 크기/형식을 확인한 후 표시합니다. 다른 메뉴판이나 구성원으로 이동한 뒤 도착한 결과를 이전 카드에 붙이지 않습니다.

## 배포와 계약

소비 앱은 기존 `FOODGUIDE_API_URL`, `FOODGUIDE_API_KEY`를 그대로 사용합니다. 별도 Food Guide 서버에는 [자동 이미지 API 패치](../../api-patches/automatic-food-images.patch)가 필요합니다. 이 패치는 이전 통화 인식 변경이 적용된 API를 기준으로 합니다. 현재 PC에는 적용했고 OpenAPI도 갱신했습니다. Render 운영 앱 배포는 별도입니다.

- `POST /v1/food-images` (202): `dishes` 1~2개. 각 항목은 `name`, `original_name`, `ingredients`, `cooking_methods`. 선택적 `retry_token`은 사용자 재시도 클릭에만 보냅니다.
- 응답 `images[]`: `image_id`, `status`, `descriptor_hash`.
- `GET /v1/food-images/{image_id}` (200): `queued/running/completed/failed`. 완료 결과는 `schema_version=food-image-v1`, `mime_type=image/png`, `image_base64`, `sha256`, `descriptor_hash`, `model`입니다.
- 기존 X-API-Key 인증·키별 분당 20회 제출 제한, 이미지 대기/실행 최대 16개, PNG 최대 4MiB, 전역 OpenAI 일일 호출 한도를 적용합니다.
- 서버 저장소: `.cache/api/food-images.sqlite3`, 보관 7일. 앱 세션 캐시는 최대 32개, 일시 연결 오류는 대기 후 확인하며 총 10분 뒤 중단합니다.

## 검증

- 백엔드 이미지·기존 API 회귀 **56개 통과**: 소유권, 인증, 동일 요청/동시 접수 중복 방지, 재시도 토큰, 재시작 복구, 결과 형식 확인.
- 이미지 클라이언트 **29개 통과**: 신규/재사용/재시도, 응답 유실, 429, 다른 음식/다른 코드, PNG/해시/크기 검증.
- UI **56개 검사 통과**: 기존 53개 및 자동 대기·완료 전환·실패 재시도 3개. 상단 이미지/추천 배지 조건 분리 후 관련 5개를 추가 재확인했습니다.
- 실제 새 메뉴판의 16개 메뉴에서 상단 두 음식 이미지가 자동 생성되어 1024px PNG로 표시됐습니다. 상세 진입·복귀 뒤 이미지 작업 수는 여전히 **완료 2건**입니다. 이 개인 메뉴판·화면·생성 결과는 저장소에 게시하지 않았으며 서버 비공개 캐시에 보관합니다.
