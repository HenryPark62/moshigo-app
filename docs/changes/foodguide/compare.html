비교를 읽는 기준

같은 공개 파리 메뉴판 사진과 예시 가족(DEFAULT_PEOPLE)을 사용했습니다. 이전은 저장소 데모 JSON 16개 메뉴, 이후는 실제 API 완료 응답 15개 ok 메뉴·3개 그룹 메뉴입니다. 서로 다른 분석 결과이므로 메뉴 수와 표현이 다릅니다. 식당을 선택하지 않은 이후 제목 “메뉴판”은 API에 없는 식당명을 만들지 않은 결과입니다.

진행·실패 화면은 운영 UI에 통제한 모의 응답을 넣었습니다. 실제 장애·지연의 증거가 아닙니다. 웹 출처 표시는 하네스 조건입니다. 이미지는 편집하거나 생성하지 않았습니다.

기존 all·local·fast는 모두 하나의 API 그룹으로 연결됩니다. 수량은 직접 고릅니다. 맛 지도·조리시간·15분 보장·직원 예상 질문·아이 전용 제안은 새 API에 없어 만들지 않습니다. 일부 선호 음식만 연결될 수 있으며 null은 0점이 아닙니다.

메인 단위 검증: 156 passed in 1.45s. 실제 호출 예시 1건은 연결 검증이며 추천 정확도 검증이 아닙니다. 외부 이미지·스크립트·서비스 없이 이 폴더의 상대 파일만 사용합니다.
